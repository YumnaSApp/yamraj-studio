# Yamraj Studio – Funny Voice Shorts Maker

Expo (React Native) app with a Swift native module (`modules/yamraj-native`):
free offline Apple Hindi voices, word-by-word captions, generated music + SFX,
9:16 1080p MP4 export, and a "Pro" in-app purchase (`com.kamran.yamrajstudio.pro`).

Build: Expo dashboard → yamraj-studio → Builds → iOS · production (or `eas build -p ios`).
